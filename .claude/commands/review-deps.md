依存ライブラリの健全性をレビューしてください。

以下の手順で確認してください:

1. `npm audit` を実行して CVE を確認する
2. `npm outdated` を実行してバージョン状況を確認する
3. `npm info <package>` で直接依存パッケージのメンテナ・更新頻度・非推奨フラグを確認する

各パッケージを以下に分類してレポートしてください:
- 問題なし
- 要注意
- 置換推奨

チェック観点:
- Critical / High CVE の有無
- メンテナが活発か（アーカイブ済みでないか）
- 最終リリースが極端に古くないか
- 直接依存ゼロ・devOnly など影響範囲も明記する
